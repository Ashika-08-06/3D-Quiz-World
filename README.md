#  3D Quiz Application

##  Project Overview
The 3D Quiz Application is an interactive quiz game developed using the Godot Game Engine. It combines a 3D environment with quiz-based gameplay to create an engaging learning experience.

## Technologies Used
- Godot Game Engine
- GDScript
- 3D Models and Assets
- Audio Assets

##  Project Contents
- 3D game environment
- Game scripts using GDScript
- Audio resources
- 3D environment assets
- Game data and resources

## Purpose
This project demonstrates the use of 3D game development, GDScript programming, and interactive game environments.
